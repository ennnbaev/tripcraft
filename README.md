# TripCraft

AI trip planner: enter a destination, dates, budget and interests, get a day-by-day itinerary generated by an LLM. Regenerate any single day with feedback, save trips, track AI usage.

Full requirements: [docs/PRD.md](docs/PRD.md)

## Stack

- **Backend:** Java 21, Spring Boot 3.5, Spring AI 1.0 (OpenAI-compatible client), Spring Data JPA, Flyway
- **Database:** PostgreSQL 17 (JSONB for itineraries)
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4, TanStack Query, React Router
- **AI providers:** Google Gemini, Groq or OpenAI, switched by Spring profile

## Run locally

Requirements: JDK 21, Maven 3.9+, Node 20+, Docker.

```bash
# 1. Database
docker compose up -d

# 2. Backend (http://localhost:8080)
cd backend
export SPRING_PROFILES_ACTIVE=gemini   # or groq / openai
export AI_API_KEY=your-key
mvn spring-boot:run

# 3. Frontend (http://localhost:5173)
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 — the page shows "Backend: UP" when everything is wired.
